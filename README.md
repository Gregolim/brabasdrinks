 🍹 Brabas Drink

Projeto de site desenvolvido para o **Brabas Drink**, com foco na apresentação do cardápio de bebidas e na simulação de pedidos, oferecendo as opções de **retirada no local** ou **entrega**.

O projeto foi criado como parte do meu processo de aprendizado em **desenvolvimento web front-end**, aplicando conceitos de HTML, CSS e JavaScript na prática.

---

 Projeto Online
🔗Acesse aqui: https://gregolim.github.io/brabasdrinks/
---

 Tecnologias Utilizadas
- HTML5  
- CSS3  
- JavaScript (Vanilla)

---

  Funcionalidades
- Exibição do cardápio de bebidas  
- Seleção de produtos  
- Opção de **retirada no local**, com exibição automática do endereço  
- Opção de **entrega**, com formulário para preenchimento do endereço do cliente  
- Validação de campos obrigatórios  
- Resumo do pedido antes da finalização  

---

  Estrutura do Projeto
- `index.html` – Estrutura principal do site  
- `style.css` – Estilização da aplicação  
- `script.js` – Lógica e interações com o usuário  

---

   Objetivo do Projeto
Praticar e consolidar conhecimentos em:
- Lógica de programação com JavaScript  
- Manipulação do DOM  
- Validação de formulários  
- Organização de código front-end
